# ব্যাকআপ ও Restore গাইড

## দুই স্তরের নিরাপত্তা
1. **Cloud (Supabase)** — প্রতিটি সফল sync-এ ডেটা cloud-এ। Supabase নিজে দৈনিক backup রাখে (project settings)।
2. **Local encrypted export** — এই ডিভাইসের ডেটার এনক্রিপ্টেড ফাইল (USB/ফোল্ডারে রাখার জন্য)।

## এনক্রিপ্টেড ব্যাকআপ নেওয়া
1. মেনু → **ব্যাকআপ**।
2. একটি **পাসফ্রেজ** দিন (মনে রাখুন — এটি ছাড়া restore হবে না)।
3. "এনক্রিপ্টেড ব্যাকআপ ডাউনলোড" → `asshifa-backup-YYYY-MM-DD.enc` ফাইল।
4. ফাইলটি USB বা নিরাপদ ফোল্ডারে রাখুন।

**প্রযুক্তি:** AES-GCM 256-bit, PBKDF2 (100k iterations) দিয়ে পাসফ্রেজ থেকে key। ফাইল = `salt(16) + iv(12) + ciphertext`।

## Restore (পরের ধাপে UI)
নিরাপদ restore প্রবাহ যা বাস্তবায়িত হবে:
1. `.enc` ফাইল নির্বাচন + পাসফ্রেজ যাচাই।
2. **Corruption check** (decrypt সফল হলে বৈধ)।
3. **Preview** — কতগুলো রেকর্ড restore হবে দেখানো।
4. **Safety backup** — বর্তমান local DB আগে অটো-এক্সপোর্ট।
5. নিশ্চিত করলে তবেই local DB প্রতিস্থাপন ও re-sync।

## সেরা অভ্যাস
- সপ্তাহে অন্তত একবার manual export নিন।
- পাসফ্রেজ নিরাপদে সংরক্ষণ করুন (হারালে ফাইল অকেজো)।
- একাধিক জায়গায় (USB + ফোন) কপি রাখুন।
