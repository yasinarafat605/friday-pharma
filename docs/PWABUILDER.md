# PWABuilder দিয়ে APK বানানো (Android Studio ছাড়াই)

এই পথে আপনি একটা **সাইন করা `.apk`** পাবেন যা ফোনে সরাসরি ইনস্টল হয়। মাত্র ৩টি ধাপ: বিল্ড → অনলাইনে তোলা → APK ডাউনলোড।

> একবার কম্পিউটার লাগবে (বিল্ড ও আপলোডের জন্য)। এরপর APK ফাইলটা যেকোনো ফোনে কপি করে ইনস্টল করা যাবে।

---

## ধাপ ১ — অ্যাপ বিল্ড করুন (কম্পিউটারে)

Node.js ইনস্টল থাকলে, প্রজেক্ট ফোল্ডারে:

```bash
npm install
npm run build
```

তৈরি হবে একটি **`out/`** ফোল্ডার — এটাই পুরো অ্যাপ (HTML/JS/আইকন)।

---

## ধাপ ২ — অনলাইনে তুলুন (ফ্রি HTTPS)

PWABuilder-এর একটা **লিংক (URL)** দরকার। সবচেয়ে সহজ: **Netlify Drop** (অ্যাকাউন্ট/কোড ছাড়াই)।

1. ব্রাউজারে যান: **https://app.netlify.com/drop**
2. আপনার **`out/`** ফোল্ডারটা মাউস দিয়ে টেনে (drag-drop) পেজে ছেড়ে দিন।
3. কয়েক সেকেন্ডে একটা লিংক পাবেন, যেমন: `https://random-name-123.netlify.app`
4. লিংকটা ফোনে/ব্রাউজারে খুলে দেখে নিন — PIN স্ক্রিন এলেই বুঝবেন ঠিক আছে।

> বিকল্প: Vercel, Cloudflare Pages, বা GitHub Pages-এও `out/` তোলা যায়। HTTPS হলেই হবে।

---

## ধাপ ৩ — PWABuilder থেকে APK

1. যান: **https://www.pwabuilder.com**
2. উপরে আপনার লিংকটা বসান (যেমন `https://random-name-123.netlify.app`) → **Start / Analyze**।
3. স্কোর দেখাবে (আমাদের অ্যাপে manifest, icon, service worker সব আছে — ভালো স্কোর আসবে)।
4. **Package For Stores** → **Android** → **Generate Package**।
5. অপশন:
   - **Package ID:** `com.asshifa.pharmacy`
   - **App name:** আশ শিফা ফার্মেসী
   - বাকি ডিফল্ট রাখুন। ("Signing key" — *New* রাখুন, PWABuilder নিজে সাইন করে দেবে।)
6. একটা **zip** ডাউনলোড হবে। ভেতরে থাকবে:
   - **`app-release-signed.apk`** ← এটাই ফোনে ইনস্টল করার ফাইল
   - `signing.keystore` + পাসওয়ার্ড ফাইল ← **নিরাপদে রেখে দিন** (ভবিষ্যতে আপডেট দিতে লাগবে)

---

## ধাপ ৪ — ফোনে ইনস্টল

1. `app-release-signed.apk` ফাইলটা ফোনে পাঠান (USB / Google Drive / WhatsApp-এ নিজেকে)।
2. ফোনে ফাইলটা ট্যাপ করুন → **"Unknown sources / এই উৎস থেকে ইনস্টল"** অনুমতি দিন → **Install**।
3. হোম স্ক্রিনে "আশ শিফা ফার্মেসী" আইকন আসবে। খুলে **৮ সংখ্যার PIN** সেট করলেই তৈরি।

---

## মনে রাখবেন

- অ্যাপ **অফলাইন** চলবে — ইন্টারনেট লাগবে না। (নেটলিফাই লিংকটা শুধু APK বানানোর সময় লেগেছিল; পরে দরকার নেই।)
- সব ডেটা ফোনের ভেতরে। **অ্যাপ আনইনস্টল বা ফোন রিসেট করলে ডেটা মুছে যাবে** — তাই নিয়মিত মেনু → **ব্যাকআপ** থেকে এনক্রিপ্টেড কপি নিয়ে Drive/USB-তে রাখুন।
- একই APK একাধিক ফোনে ইনস্টল করা যায়, তবে প্রতিটি ফোনের ডেটা আলাদা (cloud sync নেই)।
- ভবিষ্যতে অ্যাপ আপডেট দিতে হলে: আবার ধাপ ১–৩, কিন্তু PWABuilder-এ **একই `signing.keystore`** ব্যবহার করুন।
