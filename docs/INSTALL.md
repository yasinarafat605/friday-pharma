# ইনস্টলেশন গাইড

এই অ্যাপ সম্পূর্ণ local — কোনো database সার্ভার, Supabase বা `.env` লাগে না।

## পূর্বশর্ত
- Node.js ≥ 18.18

## ধাপ

```bash
# 1) dependency
npm install

# 2) চালান
npm run dev        # http://localhost:3000
```

## প্রথমবার
1. অ্যাপ খুললে একটি **৮ সংখ্যার PIN** সেট করুন (দুবার দিয়ে নিশ্চিত)।
2. ঢুকলেই ডিফল্ট খরচ ক্যাটাগরি ও সেটিংস (ফোন `+8801890163791` সহ) স্বয়ংক্রিয়ভাবে তৈরি হবে।
3. সেটিংসে গিয়ে ফার্মেসির নাম, মালিকের নাম ও **আপনার আসল ফোন নম্বর** বসান — এই নম্বরের শেষ ৪ সংখ্যাই PIN রিসেট কোড।

## PIN ভুলে গেলে
লগইন স্ক্রিন → "PIN ভুলে গেছেন?" → ফোন নম্বরের শেষ ৪ সংখ্যা → নতুন PIN।

## ডেটা কোথায় থাকে
ব্রাউজারের IndexedDB-তে (এই ডিভাইসে)। **নিয়মিত এনক্রিপ্টেড ব্যাকআপ নিন** (মেনু → ব্যাকআপ) এবং USB/নিরাপদ ফোল্ডারে রাখুন।

## PWA (ইনস্টলযোগ্য অ্যাপ)
`public/manifest.json` ও `public/sw.js` অন্তর্ভুক্ত। Production build-এ ব্রাউজার "Install app" দেখাবে। আইকন: `public/icons/icon-192.png` ও `icon-512.png`।
