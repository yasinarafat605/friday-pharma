# হাতে-কলমে পরীক্ষা — পর্ব ৪খ (লগইন ও একাধিক দোকান)

এই লেখাটি তাঁদের জন্য, যাঁরা প্রোগ্রামার নন কিন্তু অ্যাপটি নিজে চালিয়ে দেখতে চান।
ধাপগুলো ক্রমে করুন। প্রতিটি ধাপে **কী হওয়া উচিত** আর **ভুল হলে কী দেখবেন** লেখা আছে।

মনে রাখার তিনটি কথা:

1. অ্যাপটি **আগে অফলাইন**। ইন্টারনেট ছাড়াই পুরো দোকান চালানো যায়।
2. সার্ভার (Supabase) যোগ করা **ঐচ্ছিক**। যোগ না করলেও অ্যাপ সম্পূর্ণ চলে।
3. টাকা সবসময় **পয়সায়** হিসাব হয়, আর তথ্য এই ডিভাইসেই জমা থাকে।

## ভাগ ১ — সার্ভার ছাড়া (অফলাইন) চালানো

এটিই সবচেয়ে সাধারণ ব্যবহার। কোনো সেটিংস লাগে না।

### কী করবেন

```
npm install
npm run dev
```

ব্রাউজারে খুলুন: **http://localhost:3000**

### কী হওয়া উচিত

- লগইন পর্দায় অ্যাপের নাম আর লোগো দেখাবে।
- নামের নিচে একটি ছোট ধূসর লেখা থাকবে: **"অফলাইন লোকাল মোড"**।
- **লগইন / নতুন দোকান / আমন্ত্রণ কোড** — এই তিনটি ট্যাব **দেখা যাবে না**।
  এটি ঠিক আছে। সার্ভার নেই, তাই ওগুলোর কাজ নেই।
- প্রথমবার হলে **৮ সংখ্যার PIN** তৈরি করতে বলবে। দুবার একই PIN দিন।
- PIN দেওয়ার পর ভেতরে ঢুকে যাবেন।

### ভেতরে যা যা কাজ করা উচিত

ওষুধ যোগ করা, স্টক ঢোকানো, বিক্রি করা, বাকি আদায়, খরচ, রিপোর্ট, ব্যাকআপ —
সবকিছু। ইন্টারনেটের তার খুলে দিয়েও পরীক্ষা করে দেখুন; কোনো তফাত হবে না।

### ভুল হলে কী দেখবেন

| যা দেখবেন | মানে |
|---|---|
| লাল বাক্সে **"সার্ভার সেটিংস ভুল"** | `.env.local` ফাইলে ভুল মান আছে। ভাগ ২ দেখুন। |
| পর্দা শুধু **"লোড হচ্ছে…"** দেখিয়ে থেমে থাকে | ব্রাউজারে তথ্য জমা রাখা বন্ধ। ছদ্মবেশী উইন্ডো বন্ধ করে সাধারণ উইন্ডোয় খুলুন। |
| তিনটি ট্যাব দেখা যাচ্ছে যদিও সার্ভার দেননি | `.env.local`-এ পুরোনো মান পড়ে আছে। ফাইলটি দেখুন। |

## ভাগ ২ — সার্ভারের সঙ্গে জুড়ে দেওয়া

একাধিক দোকান, কর্মচারীর লগইন আর আমন্ত্রণ কোড — এগুলো তখনই চালু হয়।

> **সাবধান:** এটি দোকানের মালিকের সিদ্ধান্ত। নিচের ধাপগুলো আপনি নিজে করবেন;
> পাসওয়ার্ড বা key কারও সঙ্গে ভাগ করবেন না।

### ধাপ ১ — দুটি চলক বসানো

প্রকল্পের মূল ফোল্ডারে `.env.local` নামে একটি ফাইল বানান। নমুনা আছে `.env.example`-এ:

```
cp .env.example .env.local
```

`.env.local` খুলে ঠিক এই **দুটি** লাইন রাখুন, আর সামনের `#` চিহ্ন মুছে দিন:

```
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOi...
```

মান দুটি পাবেন: Supabase Dashboard → **Project Settings** → **API**।

- `URL` — প্রজেক্টের ঠিকানা।
- `anon key` — প্রকাশ্য key। এটি ব্রাউজারে যায়, তাই গোপন নয়। আসল সুরক্ষা
  আসে Row Level Security থেকে।
- **`service_role` key কখনো এখানে দেবেন না।** সেটি সব তালা খুলে ফেলে।

দুটি চলক বসানোর পর সার্ভার **বন্ধ করে আবার চালু** করুন (`npm run dev`)।
নইলে নতুন মান কাজ করবে না।

### ধাপ ২ — SQL ফাইলগুলো চালানো

Supabase Dashboard → **SQL Editor**। ফাইলগুলো **ঠিক এই ক্রমে**, একটির পর একটি:

| ক্রম | ফাইল | কী করে |
|---|---|---|
| ১ | `supabase/01-schema.sql` | টেবিল ও সহায়ক ফাংশন |
| ২ | `supabase/02-policies.sql` | কে কোন সারি দেখতে পাবে |
| ৩ | `supabase/03-permissions.sql` | কোন ভূমিকার কী অনুমতি |
| ৪ | `supabase/05-auth.sql` | শেষ মালিকের সুরক্ষা, কোড যাচাইয়ের সীমা, ডিফল্ট দোকান |
| ৫ | `supabase/04-column-security.sql` | **সবার শেষে** — ক্রয়মূল্যের কলাম আড়াল করা |

> ### 🚫 `00-test-harness.sql` কখনো চালাবেন না
>
> ওই ফাইলটি পরীক্ষার জন্য **নকল** লগইন ব্যবস্থা বানায়। আসল প্রজেক্টে চালালে
> Supabase-এর নিজের লগইন ব্যবস্থার উপর নকলটি বসে যাবে এবং সুরক্ষা ভেঙে পড়বে।
> শুধু `01`, `02`, `03`, `05`, তারপর `04`।

> ### কেন `04` সবার শেষে?
>
> `04` ক্রয়মূল্যের কলামগুলো আড়াল করে। এর **পরে** কোনো ফাইল টেবিলে সাধারণ
> অনুমতি দিলে সেই আড়াল মুছে যায়, আর কোনো ত্রুটিও দেখা যায় না — ক্যাশিয়ার
> নিঃশব্দে ক্রয়মূল্য দেখে ফেলবেন। তাই ক্রম বদলাবেন না।

### ধাপ ৩ — ঠিকভাবে বসেছে কিনা দেখা

লগইন পর্দা আবার খুলুন।

- **"অফলাইন লোকাল মোড"** লেখা আর থাকবে না।
- **লগইন / নতুন দোকান / আমন্ত্রণ কোড** — তিনটি ট্যাব দেখা যাবে।

### ভুল হলে কী দেখবেন

ভুল মান দিলে অ্যাপ **চুপ করে থাকবে না**। উপরে লাল বাক্সে লেখা উঠবে:

> **সার্ভার সেটিংস ভুল — ক্লাউড বন্ধ রাখা হয়েছে**
> `NEXT_PUBLIC_SUPABASE_URL সম্পূর্ণ URL নয়: "..."`

বাক্সটি **কোন চলকটি ভুল তা নাম ধরে বলে**। সেটি ঠিক করে সার্ভার আবার চালু করুন।

| যা দেখবেন | সম্ভাব্য কারণ |
|---|---|
| `... সম্পূর্ণ URL নয়` | `https://` বাদ পড়েছে, বা ঠিকানায় টাইপো |
| `... placeholder মান রয়ে গেছে` | নমুনা মান (`dummy-anon-key`) বদলানো হয়নি |
| `... সেট করা হয়নি, অথচ ... সেট করা আছে` | দুটির একটি বসাতে ভুলে গেছেন |
| `... অস্বাভাবিক ছোট` | key কপি করার সময় কেটে গেছে |
| `... মানে ফাঁকা জায়গা আছে` | উদ্ধৃতি চিহ্ন বা newline ঢুকে গেছে |

## ভাগ ৩ — চারটি যাত্রা হাতে চালিয়ে দেখা

দুটি আলাদা ইমেইল দরকার হবে। দ্বিতীয় হিসাবটির জন্য আলাদা ব্রাউজার বা
ছদ্মবেশী (incognito) উইন্ডো ব্যবহার করুন — নইলে দুটি লগইন মিশে যাবে।

### যাত্রা ১ — মালিক হিসেবে নতুন দোকান খোলা

1. **নতুন দোকান** ট্যাবে যান।
2. দোকানের নাম, নিজের নাম, ফোন, ইমেইল, পাসওয়ার্ড (কমপক্ষে ৬ অক্ষর) দিন।
3. **নতুন দোকান তৈরি করুন** চাপুন।

**ঠিক হলে:** ট্যাবগুলো চলে যাবে, উপরে আপনার ইমেইল ও দোকানের নাম দেখাবে,
আর PIN তৈরি করতে বলবে। PIN দিয়ে ভেতরে ঢুকলে উপরের দিকে **মালিক** ব্যাজ দেখবেন।

**ভুল হলে:**

| বার্তা | মানে |
|---|---|
| `পাসওয়ার্ড কমপক্ষে ৬ অক্ষরের হতে হবে` | ছোট পাসওয়ার্ড |
| `ফার্মেসি তৈরি ব্যর্থ: ...` | SQL ফাইল চালানো হয়নি বা ক্রম ভুল |
| `মালিকানা নিবন্ধন ব্যর্থ: ...` | `02-policies.sql` চালানো হয়নি |
| `User already registered` | ইমেইলটি আগেই ব্যবহৃত — **লগইন** ট্যাবে যান |

### যাত্রা ২ — লগইন করা

1. লগআউট করুন।
2. **লগইন** ট্যাবে ইমেইল ও পাসওয়ার্ড দিন।

**ঠিক হলে:** আবার PIN চাইবে, তারপর ভেতরে ঢুকবেন, আর আগের দোকানটিই চালু থাকবে।

**ভুল হলে:** `ইমেইল বা পাসওয়ার্ড ভুল` — বানান দেখুন। PIN আর পাসওয়ার্ড **আলাদা
জিনিস**: PIN শুধু এই ডিভাইসের তালা, পাসওয়ার্ড হিসাবের চাবি।

### যাত্রা ৩ — আমন্ত্রণ কোড বানিয়ে দ্বিতীয় হিসাব দিয়ে যোগ দেওয়া

এখন কোডটি অ্যাপের ভেতরেই বানানো যায়। SQL Editor-এ আর কিছু লিখতে হবে না।

#### ৩ক — মালিক হিসেবে কোড বানানো

1. মালিকের হিসাবে ঢুকুন। বাঁদিকের মেনুতে **🧑‍🤝‍🧑 সদস্য ও আমন্ত্রণ** দেখবেন।
   এই লিংকটি **কেবল মালিকই** দেখতে পান — ক্যাশিয়ার বা ম্যানেজারের মেনুতে
   এটি থাকেই না।
2. পাতাটি খুলুন। উপরে **বর্তমান সদস্য** তালিকা, আর আপনার নামের পাশে
   **আপনি** লেখা ব্যাজ থাকবে।
3. **নতুন আমন্ত্রণ কোড** কার্ডে দুটি জিনিস বাছুন:
   - **দায়িত্ব** — ক্যাশিয়ার, স্টক কর্মী, হিসাবরক্ষক, ম্যানেজার বা মালিক।
   - **কত দিন বৈধ** — ১, ৩, ৭ (ডিফল্ট), ১৪ বা ৩০ দিন।
4. **কোড তৈরি করুন** চাপুন।

**ঠিক হলে:** বড় অক্ষরে একটি কোড দেখাবে, চার-চার করে ভাগ করা, যেমন:

```
7K4M  9PQR  2XTB  H6WY
```

নিচে দায়িত্ব আর মেয়াদের তারিখ লেখা থাকবে, আর একটি **কোড কপি করুন** বাটন।

> **কোডটি এখনই পাঠিয়ে দিন।** ফাঁকা জায়গাগুলো শুধু ফোনে পড়ে শোনানোর
> সুবিধার জন্য — **কপি বাটন আসল ১৬ চিহ্নের কোডটিই নেয়**, ফাঁকা ছাড়া।
> হাতে লিখে দিলে ফাঁকা জায়গা বাদ দিয়ে, বড় হাতের অক্ষরে লিখুন।
>
> কোডে `I`, `L`, `O`, `U` — এই চারটি অক্ষর কখনো থাকে না, কারণ সেগুলো
> `1`, `0` আর `V`-এর সঙ্গে গুলিয়ে যায়। কোডে `O` মনে হলে সেটি আসলে শূন্য,
> আর `I` বা `L` মনে হলে সেটি এক।

কোডটি **একবারই** ব্যবহার করা যাবে, আর মেয়াদ শেষ হলে নিজেই অচল হয়ে যাবে।

#### ৩খ — দ্বিতীয় হিসাব দিয়ে যোগ দেওয়া

**দ্বিতীয়** ব্রাউজারে (বা ছদ্মবেশী উইন্ডোয়):

1. **আমন্ত্রণ কোড** ট্যাবে কোডটি লিখে বা পেস্ট করে **যাচাই** চাপুন।
2. দোকানের নাম আর **দায়িত্ব: ক্যাশিয়ার** দেখাবে। নিচে লেখা থাকবে
   *"দায়িত্বটি আমন্ত্রণ কোড থেকেই আসে — আপনি বদলাতে পারবেন না।"*
3. **লগইন করে আমন্ত্রণ গ্রহণ করুন** চাপুন। কোডটি মুছে যাবে না।
4. দ্বিতীয় ইমেইল দিয়ে একটি হিসাব খুলুন বা লগইন করুন।
5. লগইন হয়ে গেলে PIN পর্দার উপরে একটি বাক্স দেখবেন:
   **"আমন্ত্রণ কোড দিয়ে দোকানে যোগ দিন"**। কোডটি দিয়ে **যাচাই**, তারপর
   **&lt;দোকানের নাম&gt;-এ যোগ দিন** চাপুন।

**ঠিক হলে:** সবুজ লেখা উঠবে — *"&lt;দোকান&gt;-এ যোগ দেওয়া হয়েছে। এখন PIN দিয়ে
ভেতরে ঢুকুন।"* PIN দিয়ে ঢুকলে উপরে **ক্যাশিয়ার** ব্যাজ দেখবেন, আর ক্রয়মূল্য
কোথাও দেখবেন না — ক্যাশিয়ারের সেই অনুমতি নেই। মেনুতে
**সদস্য ও আমন্ত্রণ** লিংকটিও থাকবে না।

#### ৩গ — মালিকের পাতায় ফিরে দেখা

মালিকের ব্রাউজারে **সদস্য ও আমন্ত্রণ** পাতাটি আবার খুলুন।

- **বর্তমান সদস্য** তালিকায় নতুন মানুষটি যোগ হয়েছে, দায়িত্ব ও যোগ দেওয়ার
  তারিখ সহ।
- **চালু কোড** তালিকা থেকে ব্যবহার হয়ে যাওয়া কোডটি চলে গেছে — একবার ব্যবহার
  হলে সেটি আর কাজে লাগে না।

এখান থেকে মালিক আরও দুটি কাজ করতে পারেন:

| কাজ | কীভাবে | মনে রাখবেন |
|---|---|---|
| দায়িত্ব বদল | নামের পাশের তালিকা থেকে নতুন দায়িত্ব বাছুন | **মালিক** বানানোর কাজটি কেবল মালিকই করতে পারেন |
| সদস্য বাদ দেওয়া | **বাদ দিন** → **নিশ্চিত** | নিজের নামের পাশে বাটনটি নেই — নিজে বেরোতে চাইলে সেটিংসে **সদস্যপদ ত্যাগ** |
| কোড বাতিল | **চালু কোড** তালিকায় **বাতিল করুন** | ব্যবহার হয়ে যাওয়া কোড বাতিল করার দরকার নেই |

**ভুল হলে:**

| বার্তা | মানে |
|---|---|
| `আমন্ত্রণ কোডটি ভুল বা মেয়াদ শেষ` | বানান ভুল, মেয়াদ শেষ, বা কোডটি আগেই ব্যবহৃত |
| `লগইন ছাড়া যোগ দেওয়া যাবে না` | আগে লগইন করতে হবে |
| `অতিরিক্ত ভুল কোড চেষ্টা করা হয়েছে — ১৫ মিনিট পর আবার চেষ্টা করুন` | পাঁচবার ভুল কোড দেওয়া হয়েছে। এটি ইচ্ছাকৃত সুরক্ষা — ১৫ মিনিট অপেক্ষা করুন। |

### যাত্রা ৪ — দুই দোকানের মধ্যে বদল

এই যাত্রার জন্য এমন একটি হিসাব দরকার যেটি **দুই** দোকানের সদস্য। সহজ পথ:
যাত্রা ৩-এর দ্বিতীয় ব্যক্তি আগে নিজের একটি দোকান খুলুন (যাত্রা ১), তারপর
আমন্ত্রণ কোড দিয়ে প্রথম দোকানেও যোগ দিন (যাত্রা ৩)।

1. ভেতরে ঢুকে **উপরের বাঁদিকে** লোগোর পাশে একটি ছোট তালিকা (dropdown) দেখবেন।
   একাধিক দোকান থাকলেই এটি আসে।
2. তালিকা থেকে অন্য দোকান বেছে নিন।

**ঠিক হলে:** পাশের ভূমিকার ব্যাজ বদলে যাবে (যেমন **মালিক** → **ক্যাশিয়ার**)।
পর্দার তথ্যও সেই দোকানের হয়ে যাবে।

**ভুল হলে:** তালিকাটিই দেখা যাচ্ছে না — মানে একটিই সদস্যপদ আছে।
**সেটিংস** পাতায় **দোকান ও সদস্যপদ** কার্ডে কতগুলো দোকান আছে দেখে নিন।

### বাড়তি — সদস্যপদ ত্যাগ ও শেষ মালিকের সুরক্ষা

**সেটিংস** পাতায় নিচের দিকে **দোকান ও সদস্যপদ** কার্ড আছে। প্রতিটি দোকানের
পাশে **সদস্যপদ ত্যাগ** বাটন, আর চাপলে **নিশ্চিত, বাদ দিন** জিজ্ঞেস করবে।

- ক্যাশিয়ার হিসেবে ত্যাগ করলে কাজ হবে, দোকানটি তালিকা থেকে চলে যাবে।
- কিন্তু যে দোকানের আপনি **একমাত্র মালিক**, সেটি ত্যাগ করতে গেলে লাল লেখা উঠবে:

  > **দোকানের শেষ মালিক সদস্যপদ ত্যাগ করতে পারবেন না**

  এটি ভুল নয়, এটিই নিয়ম। মালিকহীন দোকান হয়ে গেলে ওই দোকানের তথ্যে আর
  কেউ ঢুকতে পারত না। আগে অন্য কাউকে মালিক বানাতে হবে।

| ভুল সেটিংস দিয়ে চালানো | লাল বাক্সে কোন চলক ভুল তা নাম ধরে লেখা |
| মালিক হিসেবে দোকান খোলা | **মালিক** ব্যাজ দেখা যায় |

| অন্য ভূমিকার মেনু | **সদস্য ও আমন্ত্রণ** লিংকটি নেই |
| আমন্ত্রণ কোডে যোগ দেওয়া | কোডে লেখা ভূমিকার ব্যাজ দেখা যায়, ক্রয়মূল্য দেখা যায় না |
| দোকান বদল | ব্যাজ ও তথ্য দুটোই বদলায় |
| শেষ মালিকের প্রস্থান | আটকে দেয়, লাল বার্তা দেখায় |

কোনো ধাপ মিলছে না? যা দেখেছেন তার ছবি তুলে রাখুন, আর কোন ধাপে আটকেছে সেটি
লিখে রাখুন। বার্তাগুলো ইচ্ছে করেই বাংলায় লেখা, যাতে হুবহু বলে দেওয়া যায়।
